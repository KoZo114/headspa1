# AI Skills 動画編集ワークベンチ

業務動画向けの地味な編集工程をブラウザで試せる、自分専用編集ソフトのMVPです。動画や音声を読み込み、AI文字起こしサービスの結果を貼り付けると、決定論的なルールでテロップ整形と書き出しレシピを生成します。

## できること

- 動画 / 音声ファイルのローカルプレビュー
- Web Audio API による簡易RMS無音検出
- 講師別フィラー辞書によるテロップ上のフィラー削除
- 事業用語保護辞書による `Claude Code` / `NoLang` などの語の保護
- 候補改行点 + 動的計画法による再現性のあるテロップ改行
- 1ページ最大2行、最低表示秒数を考慮したページング
- SRT、編集JSON、ffmpeg書き出しコマンドの生成

## 使い方

1. `index.html` をブラウザで開きます。
2. 「素材動画 / 音声を読み込む」からローカルファイルを選びます。
3. ElevenLabs / WhisperX / Whisper などで得た文字起こしを貼り付けます。
   - 推奨形式: `開始秒|終了秒|本文`
   - 通常テキストだけでも4秒単位の仮タイムラインで処理します。
4. 業務シーン、講師ID、字幕文字数、無音しきい値などを調整します。
5. 「7工程パイプラインを実行」を押して、SRT / JSON / ffmpeg コマンドを生成します。

## 注意

このMVPは完全な動画エンコードをブラウザ内で行いません。生成したSRTとffmpegコマンドを使い、ローカル環境やサーバー側のffmpegでMP4を書き出す設計です。
